천년의 전설 — Windows/Godot 시작 안내

중요: 이 ZIP 안의 project.godot 또는 main.tscn을 더블 클릭해 열지 마세요.
Windows가 ZIP을 임시 읽기 전용 폴더로 열면 Godot이 project.godot를 갱신할 수 없어 “불러오기 오류”가 발생합니다.

1. ZIP 파일을 다운로드합니다.
2. 다운로드 폴더에서 ZIP을 마우스 오른쪽 클릭합니다.
3. “모두 압축 풀기...”를 선택합니다.
4. 대상 폴더를 C:\Users\<사용자이름>\Documents\GodotProjects\천년의전설 같이 일반 쓰기 가능한 위치로 지정합니다.
5. 압축 풀기가 끝난 새 폴더를 엽니다.
6. Godot Project Manager를 실행하고 [Import]를 누릅니다.
7. 방금 압축 푼 폴더의 project.godot를 선택합니다. main.tscn을 직접 선택하지 않습니다.
8. 프로젝트를 열고 상단의 ▶ 실행 버튼을 누릅니다.

오류 화면의 경로에 “.zip”, “.zip.dd6”, “AppData\Local\Temp”가 들어 있으면 아직 ZIP 내부/임시 폴더에서 열고 있는 것입니다. Godot을 닫고 2~7단계를 다시 진행하세요.

프로젝트의 정상 시작 장면은 scenes/main.tscn이며 project.godot에서 자동으로 설정됩니다.
