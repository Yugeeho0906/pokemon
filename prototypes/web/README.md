# 포켓몬스터: 천년의 전설

인천 프롤로그부터 수원 첫 체육관까지 플레이하는 브라우저 체험판입니다. 제공된 최신 경량 설정집을 기준으로 제작하며, 확정된 인물·지역·포켓몬 설정을 유지합니다.

## 파일로 실행하고 보관하기

`dist/천년의전설.html`을 Chrome 또는 Edge로 열면 됩니다. 이미지와 코드가 들어 있는 단일 파일이므로 인터넷 연결이나 추가 프로그램 설치 없이 실행할 수 있습니다.

카카오톡 **나와의 채팅**에 HTML 또는 `dist/천년의전설_게임.zip`을 파일로 첨부해 보관하세요. 다른 기기에서는 내려받은 뒤 브라우저로 여세요. 카카오톡 내부 미리보기나 일부 모바일 브라우저는 로컬 HTML 실행을 지원하지 않을 수 있습니다. 소스 수정용 파일은 `dist/천년의전설_소스.zip`에 따로 담깁니다.

## 진행 상황 저장

게임의 저장 메뉴에서 현재 브라우저에 수동으로 저장하거나 저장 데이터를 JSON 파일로 내보낼 수 있습니다. 다른 기기로 옮길 때는 게임 HTML과 저장 JSON을 함께 보관하고, 새 기기에서 JSON을 불러오세요. 전투 중에는 저장하지 않습니다.

브라우저 저장은 기기·브라우저별로 분리됩니다. 로컬 HTML의 위치를 바꾸거나 브라우저 데이터를 지우면 기존 저장에 접근하지 못할 수 있으므로 JSON 내보내기가 이동·백업에 적합합니다. 내려받은 파일, 브라우저 기록·캐시 및 회사 보안 시스템 기록이 남지 않는다고 보장하지 않습니다.

## 현재 범위와 남은 작업

현재 목표 범위는 인천 프롤로그 → 특별한 이로치 랄토스 구조 → 스타팅 한 마리 선택 → 두 마리와 출발 → 야생 전투·포획 → 수원 노말 체육관과 성곽배지입니다. 이동, 충돌, 지역 이동, 대화, 전투, 회복·아이템, 동료 관리와 저장을 이 구간에서 검증합니다.

이후 지역·체육관, 전체 포켓몬 도감, 진화·메가진화, 사천왕·챔피언전, 2부 포스트게임과 인연 이벤트 전체는 아직 구현되지 않았습니다. 전투 수치와 세부 대사는 플레이 검증을 위한 임시 구현이며 확정 기획을 새로 정한 것이 아닙니다. 설정집의 게임 화면은 스타일 참고 자료이며 그대로 붙인 배경이 아닙니다.

스타팅·랄토스·일반 야생 포켓몬의 전투 그림은 플레이 확인용 임시 벡터 표현이며 최종 승인 일러스트가 아닙니다. 한국 리전폼 대여르·드레디어와 한국풍 메가가디안의 최신 승인 원본은 설정집 갤러리에 유지합니다. 이들의 게임 내 등장·육성·메가진화가 구현되었다는 뜻은 아닙니다.

## 개발

Node.js 22 이상과 Python 3.10 이상을 사용합니다. 추가 npm 패키지 설치는 필요 없습니다.

```sh
cd /workspace/pokemon
npm test
npm run build
npm start
```

`npm start`는 127.0.0.1의 8000번 포트에서 개발 서버를 시작합니다. 종료는 Ctrl+C입니다. 다른 포트는 `python3 scripts/serve.py --port 8001`로 지정할 수 있습니다. 브라우저에서 필드 이동·전투·저장·불러오기를 확인하고, 배포 HTML은 네트워크 연결을 끊은 상태에서도 확인하세요.

소스는 `src/engine.mjs`(게임 상태·전투), `src/world.mjs`(필드), `src/creature-art.mjs`(임시 포켓몬 벡터 표현), `src/app.mjs`(화면·입력), `src/style.css`로 구성됩니다. `scripts/build.py`는 이미지 원본 바이트와 모듈을 단일 HTML에 포함합니다. 승인 일러스트 유지 규칙은 [docs/ART_RULES.md](docs/ART_RULES.md)를 따릅니다.
