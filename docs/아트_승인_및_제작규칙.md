# 아트 승인 현황 및 제작 규칙

## 사용자 확인을 받은 최신 수정 디자인
- **대여르(한국 리전폼)**: `02_승인_일러스트/대여르_한국리전폼_최종.webp`. 원본 대여르처럼 **짧고 둥근 여섯 마리**, 조선 병졸 투구·갑옷, 선두 태극 방패. 인간형으로 늘씬하게 그리면 안 됨. 사용자가 '그렇지 그렇지'라고 승인.
- **드레디어(한국 리전폼)**: `02_승인_일러스트/드레디어_한국리전폼_최종.webp`. 원본의 작은 식물 포켓몬다운 체형, 큰 꽃 머리 장식, 잎 팔, 꽃잎 한복 치마. 인간형 비율 금지. 사용자가 '좋다'고 승인.
- **한국풍 특수 메가가디안**: `02_승인_일러스트/메가가디안_한국풍_최신승인.webp`. 최근 한국풍 디테일을 강화한 버전으로 사용자가 '좋아'라고 승인. 원본 가디안다운 머리·얼굴·몸체 실루엣 유지, 남색/흰색/분홍색/금색 한복 문양. 기존 디자인 계보를 존중하고 지나치게 인간처럼 바꾸지 않음.

## 캐릭터 기존 승인
- 서하린 캐릭터 시트, 백서화 사용자가 제공한 디자인, 여성 관장 4인 시트, 흑월단 간부 4인 시트는 기존에 수용됨.
- 사천왕/강현/무영 시트는 제작된 콘셉트 자료. 개별 최종 승인으로 과장하지 말 것.
- 리전폼 12종 합본은 **초안**. 대여르·드레디어만 별도 최신 승인 디자인으로 교체해 사용.

## 필드 그래픽 최우선 지침
사용자는 최신 메가가디안 콘셉트 시트 하단 **'필드 구현 예시'**의 분위기를 매우 선호. 고품질 탑다운/약한 쿼터뷰 2D, 작고 귀여운 SD 캐릭터, 섬세한 한국식 기와·돌길·벚꽃·물·그림자·조명, 선명하고 화사한 색감. 필드에는 SD, 대화/배틀/이벤트에는 고품질 일러스트. 과도하게 거칠거나 조잡한 픽셀 그래픽 지양. 참고 그림을 단순 배경 이미지로 붙이는 대신 이동 가능한 타일맵, 충돌, 애니메이션과 레이어로 재구성.

## 이미지 자료 주의
일러스트는 시각적 기준. 이미지에 자동으로 생성된 문구, 타입, 수치, 지명, 스킬은 오류 가능성이 있으므로 마스터 기획서 우선. 원본 이미지 자체는 아직 편집 가능한 레이어나 게임용 스프라이트 아틀라스가 아님.


## 최근 추가 수정: 캐릭터 SD 표현 범위
- 캐릭터 일러스트 자체를 SD/치비 비율로 바꾸지 말 것. 대화·배틀·이벤트에서는 원래 승인된 고품질 전신/반신 일러스트 비율 유지.
- 필드에서 걸어 다니는 작은 캐릭터에만 SD 스타일 사용.
- 14인 캐릭터 일괄 재해석 콘셉트는 최종 승인 원본을 대체하지 않음.
