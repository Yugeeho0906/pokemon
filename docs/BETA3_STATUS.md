# 베타 3차 — 경량 패키지 기반 1차 수정 (2026-10-28)

사용자가 제공한 `경량.zip`을 기준으로 기존 코드를 가져온 뒤 수정했습니다. 원본 Manus 맵·주요 인물 시트·포켓몬 그래픽·효과음은 패키지에서 빠져 있습니다. 이 결과는 **전체 개선 완료판이나 원본 에셋을 포함한 실행 배포판이 아닙니다.** 기존 폰트와 승인 참고 이미지는 저장소에 보존했습니다. 기존 이벤트, 체육관 파티·퍼즐, 저장 버전은 유지합니다.

## 수정 파일

- `game/field_data.json`, `game/field_data.gd`: NPC 배치와 풀숲 범위·종류·확률·성장 레벨 데이터.
- `game/field.gd`: 표시/대화 좌표 공유, 이도윤 역할 수정, F8 좌표/풀숲 경계 디버그, 원본 맵 픽셀을 활용한 발 앞 가림·이동 흔들림 구현.
- `game/encounters.gd`, `game/main.gd`: 이동거리 누적 조우, 공통 전환 연결, 메뉴/입력 잠금, 종료 후 복귀·쿨다운·취소 처리.
- `game/battle_transition.gd`: WILD/TRAINER/GYM/STORY 공통 셔터 전환. 관장전은 별도 색조. 포켓몬 등장 시 이동/페이드 처리(스프라이트가 있을 때).
- `game/engine.gd`: 기존 야생 레벨 공식의 상수를 필드 데이터에서 읽도록 변경. 피해·경험치·포획 수식은 유지.
- `game/trainers.gd`, `assets/trainers/battle_atlas.png`: 12종 전투 등장용 **검토 시안**, 도로·체육관 트레이너 타입과 연결.
- `tests/test_beta3.gd`: 배치 접근성, 조우, 전환 중복/입력, 복귀, 취소 및 아틀라스 검사.
- `tests/test_scene.gd`: 기존 장면 검사가 비동기 전환을 기다리도록 수정. 전체 실행은 원본 에셋 복원 후 필요.
- `tests/preview_trainers.gd`: 실제 Godot에서 12종 시안 미리보기 출력.
- `scripts/build_pc.py`: 추가 게임 JSON을 소스 ZIP에서 누락하지 않도록 수정.

인천 숲은 독립 맵이 아닌 인천 맵 내 이벤트 구역입니다. 수원 외부 NPC 역할은 건물 상호작용이며 새 인물을 임의로 추가하지 않았습니다. 테스트는 명시적 충돌 데이터와 BFS 접근성을 사용합니다. 단일 배경 PNG에 그려진 지붕·나무와의 시각적 겹침, 실제 발 기준 깊이 정렬은 **미검증**입니다. PNG에서 분리된 전경 가림 레이어도 아직 없습니다.

## 조우와 전환

- 기본 확률: 풀숲 실제 이동 1타일당 10%. 프레임마다 추첨하지 않습니다. 쿨다운·정지·비풀숲·마을에서는 판정하지 않습니다.
- 현재 야생 종류 구구/캐터피 각 50%, 기존 Lv.5 + 도로 승리 수(최대 Lv.10) 성장 유지.
- F9는 디버그 빌드에서만 100%/기본 확률을 전환합니다. 저장 파일에 기록하지 않고 일반 시작은 10%입니다.
- 필드→셔터→배틀→스프라이트 등장→메뉴 활성화, 종료→셔터→필드 복귀. 플레이어 위치·방향을 전환 효과가 수정하지 않습니다. 전멸 시 센터 이동은 기존 엔진 규칙입니다.
- 저장 불러오기/새 게임으로 전환을 취소하면 이전 비동기 작업이 새 상태를 변경하지 않게 세대 번호를 검사합니다.
- 수동 대화 배틀은 유지합니다. **트레이너 시선 감지/느낌표/접근 이동, 조우 효과음·주변 풀숲 큰 흔들림, 관장 전용 승인 시트·배지 획득 별도 애니메이션은 미구현**입니다.

## 트레이너 12종

엘리트 남성, 엘리트 여성, 반바지 꼬마, 미니스커트, 남학생, 여학생, 등산가, 배낭여행자, 태권도 수련생, 무술가, 연구원, 수영선수.

독립 디자인의 투명 PNG 전투 시안을 한 아틀라스에 제작했습니다. 게임은 각 영역을 AtlasTexture로 읽으며 도로/체육관 트레이너에 표시합니다. 이것은 12종의 **4방향 걷기까지 완료했다는 의미가 아닙니다.** 외곽 픽셀·발 정렬 최종 다듬기와 승인도 필요합니다. 기존 필드 규격은 권장 32×48이 아니라 실제 48×48, 4열×3행입니다. 해당 12종 필드 시트는 아직 제작하지 않았으며 기존 주요 캐릭터 시트를 교체하지 않았습니다.

## 검증 및 실행

```sh
bash scripts/godot.sh --headless --editor --import --quit
bash scripts/godot.sh --headless --script tests/test_engine.gd
bash scripts/godot.sh --headless --script tests/test_beta3.gd
# 실제 화면과 원본 에셋이 준비된 뒤 전체 회귀
bash scripts/godot.sh --audio-driver Dummy --script tests/test_scene.gd
# 새로 만든 전투 시안만 미리보기
bash scripts/godot.sh --audio-driver Dummy --script tests/preview_trainers.gd
```

엔진 27그룹 318검사, 새 헤드리스 검사 93개 및 실제 X11/OpenGL에서 동일한 93개 통과. 새 검사는 원본 누락 시 폴백 UI를 포함한 코드 연결 검사이며 원본 그래픽 검증이 아닙니다. 전체 457/489개 장면 검사는 첨부본 문서의 이전 제작자 결과이며 이번 수정본의 결과로 주장하지 않습니다.

실제 Godot/X11로 `artifacts/beta3/trainers-godot-preview.png`를 캡처했습니다. 이것은 트레이너 시안 갤러리이며 최신 인천~수원 플레이 화면이 아닙니다. 원본 `assets/generated/`, 관련 포켓몬 카탈로그 에셋과 소리를 연결한 뒤 전체 장면 검사, 풀숲 가림·NPC 외형/깊이·배틀 등장 시각 검수를 해야 합니다. 원본 에셋 없는 Windows 실행 파일은 배포하지 않습니다.

경량 수정 ZIP은 기존 원본 프로젝트를 백업한 복사본에 상대 경로 그대로 합칩니다. `.godot` 캐시는 Godot가 다시 생성합니다. ZIP에 없는 원본 에셋을 삭제하지 마세요. 새 게임을 시작하거나 저장 파일을 초기화할 필요는 없습니다.
