# 《포켓몬스터: 천년의 전설》 통합 기획 v2.0

> 기존 설정집의 확정 설정 + 2026-10-26까지 대화에서 추가한 게임 시스템 설계. **이 패키지의 이미지 파일을 직접 확인하여 사용한다.** 수치·파티·세부 동선은 밸런스 검증 전 개발안이다.

## 1. 최우선 준수 사항
- 기존 세계관·스토리·인물·포켓몬 범위·승인 일러스트를 임의 변경하지 않는다.
- **필드 이동 화면은 `04_게임화면_스타일/최우선_필드스타일_메가가디안시트.webp`의 오른쪽 아래 '필드 구현 예시'가 기준**. 한국풍 기와·돌길·벚꽃·풍부한 조명·정교한 탑다운/약한 쿼터뷰 2D. 지나치게 거친 저해상도 도트로 바꾸지 않는다.
- 필드에서만 작은 SD 캐릭터. 대화·배틀·컷신에서는 승인된 정상 비율의 고품질 캐릭터 일러스트.
- 게임용 타일·스프라이트·애니메이션은 레퍼런스 이미지를 참고하여 별도 구현한다. 콘셉트 시트 전체를 필드 배경으로 붙이지 않는다.
- 공식 포켓몬 외형은 식별 가능하도록 정확히 재현하며, 한국 리전폼은 승인본 우선. 외부 공개·배포 전 IP 권리 검토 필요.
- 강현이 흑월단 수장이라는 사실은 **서울 챔피언전에서 처음 공개**. 무영은 포스트게임 왕궁의 최종 인물.

## 2. 게임 구성
한국 지형을 알아볼 수 있는 **한반도 월드맵**. 실제 도시의 대략적인 지리 관계 유지. 진행 순서는 인천(이로치 랄토스 구조→백서화 연구소에서 스타팅 선택)→수원(노말 이도윤)→설악산(얼음 설유나)→대전(전기 한태오)→전주(페어리 윤서린)→광주(풀 백시온)→대구(불꽃 강태준)→경주(고스트 문시연)→부산(물 해나리)→제주(흑월단 의식, 천화구 선택)→서울(사천왕·강현)→포스트게임 울릉도·독도 및 경주 인근 천령 왕궁(무영).

## 3. 도로 및 레벨링
도로를 남발하지 않는다. 메인 도로 8개, 부산→제주는 선박, 제주→서울은 교통수단. 도시 위치를 게임 순서대로 재배치하지 않는다. **도로 수를 줄여도 육성량은 줄이지 않는다.** 주요 길+선택 샛길+트레이너+야생 포켓몬+아이템+지역별 특색 있는 이벤트. 필수 전투만으로는 관장 에이스보다 약간 낮게, 보통 탐험 시 비슷하게, 샛길 탐험 시 조금 높게 도달하도록 테스트.

| 구간 | 도로 | 첫 탐험 목표 | 트레이너 목표 | 관장 에이스 Lv. |
|---|---|---|---|---|
| 인천→수원 | 1번도로 | 12~18분 | 5~6 | 16 |
| 수원→설악산 | 2번도로+등산로 | 18~25분 | 6~8 | 24 |
| 설악산→대전 | 3번도로 | 15~20분 | 5~7 | 31 |
| 대전→전주 | 4번도로 | 15~20분 | 5~7 | 38 |
| 전주→광주 | 5번도로 | 18~25분 | 6~8 | 45 |
| 광주→대구 | 6번도로 | 18~25분 | 6~8 | 52 |
| 대구→경주 | 7번도로 | 20~25분 | 7~9 | 58 |
| 경주→부산 | 8번도로 | 20~25분 | 7~9 | 64 |

시간·인원·레벨은 목표치이며 플레이 테스트 후 조정. 길만 늘리거나 반복 노가다를 강제하지 않는다. 체육관·던전·라이벌·흑월단 전투도 육성량에 합산.

## 4. 배틀·포켓몬 시스템
- 18타입, 턴제, 포획, 상태이상, PP, 특성, 성격, IV/EV, 진화, 도감, 상점, 포켓몬센터, 박스, 레벨 상한 100.
- 배틀 기믹은 **메가진화만**. 창작 메가는 메가울창령·메가진화랑·메가해류신·메가천화구·특수 한국풍 이로치 메가가디안 총 5종. 기존 공식 메가진화는 별도. Z기술·다이맥스·테라스탈 금지.
- 스타팅: 푸르내→푸르솔이→울창령(풀/페어리), 화랑이→불호령→진화랑(불꽃/격투), 파도링→물결달이→해류신(물/드래곤). 여섯 수호자: 천화구, 천화린, 월화록, 청해룡, 금련화, 월해령. 한국 리전폼 12종. 기존 설정의 하늘리온·테라리온 보존. **추가 창작 포켓몬을 임의로 만들지 않음.**
- 자동 경험치 공유: 학습장치 아이템 없이 처음부터 적용. 살아 있는 전투 참여 파티원 기준 경험치 100%, 미참여 파티원 50%, 기절·박스 포켓몬 0%. 다수 참여 시 각 참여자에게 기준 경험치를 지급하는 개발안. 상대 레벨에 따른 가변 경험치로 과레벨 방지.
- 난이도 쉬움·보통·어려움. AI·보스 레벨·아이템 사용 조절, 타입 상성·종족값은 불변. 게임 중 난이도 변경 가능.
- 기술 최대 4개, 무료 기술 떠올리기, 기술머신 무제한 재사용, 특별 이벤트 기술은 해금 조건 적용.
- 파티 6마리, 초기 박스 8×30칸 자동 확장, 일반 필드 원격 박스, 전투 중 사용 불가. 특별 랄토스는 일반 이로치와 구분되는 고유 출처 플래그 보유.

## 5. 탐험·편의 시스템
- 첫 방문 포켓몬센터/거점 등록 후 월드맵에서 무료 빠른 이동. 미방문·스토리 미해금 지역 이동 불가.
- 퀘스트 일지: 메인/서브/인연/포스트게임, 목표와 지도 마커, 스포일러 미노출.
- 저장: 위치·파티·박스·아이템·도감·배지·퀘스트·컷신 플래그·인연·난이도, 세이브 버전 관리.
- 트레이너 재대결, 회복 지점, 선택 탐험로 제공.

## 6. 캐릭터·스토리 이벤트
- 서하린은 인천 스타팅 라이벌→수원 경쟁→대전 전략 성장→전주 신뢰→대구 공동 작전→부산 6마리 파티→제주 협력→서울 최종 라이벌전→포스트게임 재대결. 플레이어 스타팅에 타입상 유리한 스타팅 선택.
- 흑월단 에리카(잠입·정보: 수원/대전), 레이나(환영: 설악산/전주), 카이엔(전투: 광주/대구/부산), 시오리(고고학·의식: 경주/제주). 간부가 강현의 정체를 미리 폭로하지 않음.
- 강현: 28~29세, 챔피언, 메가메타그로스. 제주 의식 저지 후 서울 챔피언전에서만 배후 정체 공개.
- 무영: 27세, 천령국 마지막 왕실 후예, 왕국 부활 목표, 일반 메가가디안 사용. 포스트게임 왕궁 최종전.
- 인연 9명: 서하린, 백서화, 설유나, 윤서린, 문시연, 해나리, 세아린, 카렌 유즈화, 무영. 각 0~100 독립 호감도, 친분/신뢰/특별 이벤트/에필로그. 여러 루트 동시 진행 가능, 특별 에필로그 한 명 선택. 무영은 포스트게임 한정. 관계 중심의 가벼운 애니메이션풍 연출, 메인 모험 방해 금지.

## 7. 포스트게임
서울 챔피언전 후 경주 고문서→수호자 진실 탐색→울릉도·독도 월해령→경주 인근 천령 왕궁→무영 최종전. 수호자 재도전·포획, 관장·사천왕·서하린 재대결, 도감 완성, 인연 후일담. 무영은 특수 한국풍 메가가디안이 아닌 일반 메가가디안 사용.

## 8. 구현·검수 우선순위
1. 승인된 필드 스타일로 인천 마을의 실제 이동 가능한 맵, 충돌, NPC, 대화, 저장.
2. 랄토스 구조→스타팅 선택→서하린 첫 대결→1번도로→수원 관장까지 완전 플레이 가능한 세로 슬라이스.
3. 자동 경험치 공유, 기술 관리, 포획, 박스, 월드맵·빠른 이동, 퀘스트.
4. 전 지역·8체육관·흑월단·제주·서울 챔피언전.
5. 인연·포스트게임·아트 품질·레벨링 자동화 테스트.

**주의:** ZIP의 승인 이미지가 실제 게임 스프라이트/타일셋으로 완성되어 있다는 뜻은 아니다. 참조 이미지를 보고 게임용 에셋을 제작·검수해야 한다. 포스터/합본의 글자와 수치는 오류가 있을 수 있으므로 문서의 명시적 확정 설정 우선.
