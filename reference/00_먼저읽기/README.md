# 《포켓몬스터: 천년의 전설》 게임 제작 전달 패키지

**이 패키지는 기존 채팅에서 확정한 게임 기획과 시각 자료를 다른 제작 채팅/개발 환경으로 넘기기 위한 인수인계 자료입니다.**

## 반드시 지킬 사항
1. 확정된 설정을 임의로 재설계하지 말 것. 사용자가 이미 승인한 디자인은 유지.
2. 공식 포켓몬 1~9세대의 전투 구조를 참고하되, 저작권이 있는 코드·이미지·음원은 무단 복제하지 말 것. 실제 공개·배포 전 권리 검토 필요.
3. 창작 포켓몬 추가 금지: 스타팅 3계열(9종), 전설 수호자 6종, 기존 포켓몬의 한국 리전폼 12종만. 신규 메가진화는 5종만.
4. 필드는 세련된 **고품질 탑다운/쿼터뷰 2D RPG**, 아담한 SD 캐릭터, 풍부한 한국풍 타일 배경. 조잡한 단순 도트 금지.
5. 캐릭터는 대화·배틀·이벤트에서 일러스트, 필드에서는 SD로 표현.
6. 메인 스토리는 체육관 여행 중심, 자연스러운 사건 연결과 복선 회수. 강현의 비밀은 **서울 챔피언전에서만** 드러남.
7. 이미지에 포함된 자동 생성 텍스트/수치/포켓몬 이름 오타는 **기획 문서의 표기**가 우선.

## 이미지 폴더
- `02_승인_일러스트`: 사용자가 승인한 것으로 확인된 디자인 및 참고 시트. 합본 이미지 속 모든 개별 디자인이 최종 승인이라는 뜻은 아님.
- `03_콘셉트_참고`: 제작된 초안·포스터. 설정집 원본이 아니라 시각적 참고.
- `04_게임화면_스타일`: 필드 그래픽과 SD 캐릭터 표현을 위한 시각 레퍼런스. 실제 게임 스프라이트·타일셋은 별도 제작 필요.
